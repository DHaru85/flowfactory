# 2026-08-19 工具分发基础设施建设 - 服务层 - 修改

## 用户需求理解

在 Agent 配置 ORM（`agent_tool` / `agent_mcp_server`）与知识检索、观测 Collector 已落地的前提下，先建设 **ToolExecutor 工具分发**，作为后续自主规划智能体（deepagents）的前置能力。本轮**不编译规划图、不新增 Flow 节点 kind、不做 FastAPI / SSE**。

对齐 `docs/design/data_schema_server.md`：`ToolExecutor.execute(ToolCallRequest) -> ToolCallResult`，按 `agent_tool.kind` 分发：`builtin` / `http` / `mcp`。

### 澄清过程

| 事项 | 用户确认 |
| --- | --- |
| 范围 | 仅 ToolExecutor 分发；不接规划循环、不改 FlowRuntime 节点集 |
| MCP | **必须预留接入** |
| 内置工具 | 本轮只做 `kb_retrieve` |
| HTTP | URL 只来自 config，禁止 arguments 覆盖；超时可配 |

### 现状（不重复建设）

- 表：`agent_tool`、`agent_mcp_server` 已存在；仓储有 `AgentConfigRepository.tool` CRUD，缺 `get_tool_by_code`。
- 检索：`RetrievalService.search` 可用，尚未挂成工具。
- 观测：`TraceCollector.record_tool` 已有，工具执行未自动调用。
- 图运行时仍只有 `passthrough` / `interrupt` / `llm`。

## 施工方案（已锁定）

### 1. 配置

- `tool_http_timeout_seconds=30`
- `tool_http_max_body_bytes=1048576`
- `kind=mcp` 走 `McpClientSession` 工厂；测试注入 Fake；生产缺配置则 `execute` 返回失败，不在 import 期崩溃

### 2. 序列化对象

`service/tools/schemas.py`：`ToolCallRequest`、`ToolCallResult`。参数按 `agent_tool.schema` 做 JSON Schema 校验。

### 3. ToolExecutor

按 `tool_code` 读库 → 校验 → `builtin` / `http` / `mcp` 分发。业务失败与未知 kind 返回 `ToolCallResult(success=false)`。`session` 为空在构造期抛错。有活跃 Collector 时 `record_tool`（摘要脱敏）。

HTTP：method/url/headers 来自 config；`param_in` 为 `body` 或 `query`。

### 4. Builtin `kb_retrieve`

`query_text`、`collection_ids`、可选 `top_k` / `filters`。output 为 chunk_id / doc_id / score / snippet / source。

### 5. MCP 预留

`McpClientSession` 协议、`FakeMcpClientSession`、`SdkMcpClientSession`、`get_mcp_session()` 可 override。

### 6. 仓储

`get_tool_by_code`、`get_mcp_server`。不做 SkillRuntime。

### 7. 依赖与测试

`httpx`、`jsonschema`、`mcp`。单测覆盖 schema、kb、HTTP MockTransport、Fake MCP、观测。

## 方案待澄清事项

无待澄清事项（方案锁定）。

## 验收标准

1. ruff 无 error；pytest 通过。
2. `ToolExecutor.execute` 按 kind 分发；未知 code/kind 与 schema 失败返回 `success=false`。
3. `kb_retrieve` 能调通检索服务（测试可 Fake）。
4. HTTP URL 不被 arguments 覆盖；MockTransport 可断言 method/url。
5. 默认不连真实 MCP；注入 Fake 可调通。
6. 有活跃 TraceCollector 时写出工具调用缓冲。
