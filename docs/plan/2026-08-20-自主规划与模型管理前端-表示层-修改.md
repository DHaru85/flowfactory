表示层提供模型管理、Agent 配置（Profile/技能/工具/MCP/Beat）、规划会话与工作流会话（Ant Design + Ant Design X），对接已有 SSE。

后端配置/模型/会话/规划/RBAC 已落地。本轮按 unreached 原文五条施工，**不含** Studio 画布（另留 unreached）。

## 需求中的待澄清事项

无待澄清事项。

## 施工方案

1. 工程：`src/frontend`，Vite + React + TypeScript；源码在 `source/`；开发代理 `/api` 到后端；不引入 Vercel AI SDK。
2. 类型与 Axios：按 `data_schema_client` 建传输类型；Bearer；401 尝试 refresh 后重试；403 提示、不登出。Token 放 `sessionStorage`。
3. 壳：登录页；登录后 `GET /auth/apps` 生成菜单；无 `can_use` 的路由不可进。`conversation` 拆「规划会话 / 工作流会话」两个入口。
4. `models`：LLM 表；密钥只写不回显；`has_api_key` 提示已配置。
5. `agent_config`：Profile / Skill / Tool / MCP / Beat 分栏；绑定覆盖写入（主体 UUID 手填）；Beat `flow_id`/`profile_id` 互斥。
6. 会话：共用消息列表 + `Sender`；`fetch` SSE（带 Authorization）；拼接 `speaking`；忽略 keepalive。规划选 Profile；工作流填 `flow_id`（若有 studio 可见则拉 published-codes）。
7. `npm run build` 通过。

本轮不做：Studio 画布、知识库、Docker 前端镜像。
