# PG 异步连接池改造

## 用户需求理解

数据连接层 PG 引擎改为 **异步连接**（`create_async_engine` + `AsyncSession`），连接池 **最大连接数默认 20**。

## 待澄清事项

无待澄清事项。

## 施工方案

1. **配置**（`settings/config.py`）
   - `db_pool_size` 默认改为 `20`，`db_max_overflow` 默认 `0`（总上限 = 20）
   - 新增 `async_database_url`（`postgresql+psycopg_async://`）
   - `database_url` 保留为同步 URL，供 Alembic / bootstrap 使用

2. **引擎**（`service/database/engine.py`）
   - `get_async_engine` / `get_async_session_factory`
   - `dispose_engines` 异步释放

3. **Session**（`service/database/session.py`）
   - `session_scope` / `get_db_session` 改为 async

4. **Bootstrap**（`service/database/bootstrap.py`）
   - `verify_connection` 改为 async
   - `ensure_database_exists` 保持同步 admin 连接

5. **仓储**（`service/persistence/*`）
   - 基类与各域仓储方法改为 `async def`，使用 `await session.*`

6. **依赖与测试**
   - 增加 `greenlet`、`pytest-asyncio`
   - 集成测试改为 async

## 方案待澄清事项

无待澄清事项（方案锁定）。

## 验收标准

1. ruff 无 error
2. pytest 全部通过
3. Alembic 仍使用同步 URL 可正常迁移
