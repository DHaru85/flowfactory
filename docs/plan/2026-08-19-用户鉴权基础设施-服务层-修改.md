# 2026-08-19 用户鉴权基础设施建设 - 服务层 - 修改

## 用户需求理解

在 Permission 域 ORM / 仓储 / JWT Redis key 已落地的前提下，建设**用户鉴权**服务层基础设施，覆盖：

1. **认证（AuthN）**：本地账号密码登录；短 JWT access + opaque refresh；refresh 轮换与 `family_id` 重用检测；登出将 access `jti` 写入 Redis 黑名单；踢人/改密更新 `revoke_before`。
2. **鉴权（AuthZ）**：`PermissionService` 按用户角色合并 `sys_role_asset_grant`；超管直通；可选 Redis 热缓存。
3. **LDAP 接入预留**：`LdapAdapter` 协议含 bind / 同步 / 映射；登录链在 `ldap_enabled` 时走目录 bind + JIT 建本地用户；本轮默认关闭且不要求真实目录可达。

对齐 `docs/design/data_schema_server.md`。本轮只做服务层，不做 FastAPI / SSE / docker-compose。

## 施工方案（已锁定）

### 1. 配置

- JWT：`jwt_secret`（开发默认）、`jwt_algorithm=HS256`、`jwt_access_ttl_seconds=900`、`jwt_refresh_ttl_seconds=1209600`、`jwt_issuer=flowfactory`
- LDAP：`ldap_enabled=false`、`ldap_host`/`port`/`use_tls`/`bind_dn`/`bind_password`、`ldap_user_search_base`、`ldap_group_search_base`、`ldap_user_filter`（默认 `(uid={username})`）、`ldap_username_attr=uid`、`ldap_default_org_code`（JIT 用户所属组织）、`ldap_sync_beat_enabled=false`

### 2–6. Auth / JWT / Permission

与确认前方案一致：Argon2id、PyJWT HS256、`AuthService`、`PermissionService`、`GrantCacheStore`、仓储补 refresh/family/grants。

**登录验密顺序（LDAP 预留点）**：

1. 本地用户且存在 `password_hash` → 只验 Argon2，失败不回落到 LDAP。
2. 否则若 `ldap_enabled` → `LdapAdapter.bind_user` → `map_identity` → 写入/关联 `sys_user` + `sys_external_identity`（无本地密码）。
3. 否则 `invalid_credentials`。

### 7. LDAP 接入面（本轮必须落地的预留）

| 模块 | 职责 |
| --- | --- |
| `LdapAdapter` 协议 | `connect` / `close` / `bind_user` / `fetch_entries` / `sync_users` / `sync_departments` / `map_identity` |
| `FakeLdapAdapter` | 内存目录，单测 bind + sync |
| `Ldap3Adapter` | 真实 `ldap3` 实现；`ldap_enabled=false` 时工厂不实例化 |
| `get_ldap_adapter()` | 可 override；未启用返回 Fake 仅供测试注入，生产关闭时登录不调用 |
| Celery `sync_ldap_directory` | 骨架：写 `sys_ldap_sync_job`，调用 `sync_users`；默认不进 Beat |

适配器**不依赖 ORM**；`map_identity` 返回 `ExternalIdentityMapping`，由 `provision_ldap_user` 写库。后续只换 `Ldap3Adapter` 与配置即可接入真实目录。

### 8–11. 依赖、测试、施工状态、验收

依赖：`PyJWT`、`argon2-cffi`、`ldap3`。测试含本地登录全链路 + Fake LDAP bind/JIT/sync。模块开工标施工中，通过后空闲。不新增 FastAPI 与 docker-compose。

## 验收标准

1. ruff 无 error；新增/既有 pytest 通过。
2. 本地 login → verify；logout / revoke_all 立即失效；refresh 轮换与 family 重用检测正确。
3. `PermissionService.check` 超管直通、RBAC grant 正确。
4. `ldap_enabled=false` 时登录不访问目录；注入 FakeAdapter 且启用时可用 LDAP 账号登录并落 `sys_external_identity`。
5. `Ldap3Adapter` 可独立构造（配置齐全时），缺配置不在 import 期崩溃。
