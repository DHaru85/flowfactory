## 用户需求理解

第 1 轮只登记绑定与 `sys_asset`，任意 JWT 可读写配置。本轮按 **双层绑定** 限制可见性，并接通管理员写权限：

1. **应用层绑定**：组织 / 部门 / 角色 / 个人绑定到 `sys_asset(application, app_key)`（`agent_resource_binding.resource_type=application`，`resource_id` 为该资产 UUID），决定用户能看见、使用哪些应用。
2. **资源层绑定**：Profile / Skill / Tool / MCP 仍按既有绑定命中主体；普通人只见命中资源。
3. **平台管理员**：FlowFactory 的 RBAC 管理员与超级管理员为 **同一角色定义**，落在 `sys_user.is_superuser`。该身份天生具备全部应用与资源配置的查看、修改与删除权限。

不把 binding 升到 Permission 域。不删 `owner_organization_id`。不做表示层。

## 施工方案

### 1. 平台管理员与两档应用权限

- `is_superuser`：跳过一切应用绑定与资源绑定，可查看/修改/删除全部。
- 非超管：
  - **可见可用**：应用绑定或角色 grant 命中 `read` / `use` / `write` / `admin` 之一。
  - **修改与完全控制**：命中 `write` / `admin`。models、studio、agent_config（含 Beat）均按此两档；不把 write 与 admin 再拆成三档。
- 角色 grant（`PermissionService.check`）与应用绑定 **并集**。
- 组织范围仅直接 `organization_id` / `department_id`，不沿 `parent_id`。

### 2. 应用资产与应用绑定

- 启动幂等登记 `sys_asset`：`application` × 已注册 `app_key`。
- 应用绑定写入 `agent_resource_binding`（`resource_type=application`）。
- `GET /api/v1/auth/apps`：当前用户可见应用及 `can_control`。`auth` 对已登录用户始终可见。`GET /health` 的 `apps` 不过滤。
- `GET/PUT /api/v1/auth/apps/{app_key}/bindings`：**仅超管**。主体不存在 `400 subject_not_found`。未知应用 `404`。

### 3. 应用层拦截

失败进入应用：`403 app_forbidden`。资源不存在或普通人越权探测：`404`。

| 应用 | 可见可用 | 修改与完全控制 |
| --- | --- | --- |
| `auth` | 登录族 + `me` / `apps`（JWT） | 应用绑定 API 仅超管 |
| `models` | 列表/详情 LLM | 创建/PATCH/停用 |
| `studio` | 列表/详情 Flow 与目录；Profile/Tool 目录再按资源绑定过滤 | 草稿/发布/新草稿 |
| `agent_config` | 列表/详情；Profile/Skill/Tool/MCP 按资源绑定过滤；Beat 无行级，有可见可用即可列表 | 创建/PATCH；Beat 启停；资源 `GET/PUT .../bindings` |
| `conversation` | 列表/详情/SSE（仍校验属主） | 建会话、发消息。规划 Profile 须资源 `use` 可见，否则 `404 profile_not_found` |

### 4. 仓储与服务

- `AccessControl`：主体解析、应用两档、资源可见 id。
- `AgentRepository.list_bindings_for_subjects`；`Repository.list_by_ids`。
- 索引 `idx_agent_resource_binding_subject (resource_type, subject_type, subject_id)`。
- 不改 Celery Beat 调度鉴权。

### 5. 明确不做

表示层；限流；binding 迁入 `sys_role_asset_grant`；知识库 HTTP；父组织继承；种子普通角色。

设计文档去掉「不审 RBAC」。单测覆盖：无应用绑定 403；普通人看不到未绑定 Profile；绑定到组织可见；超管全权；无完全控制改绑定 403；跨范围 404；models/studio 可见不可改；会话属主回归。ruff。
